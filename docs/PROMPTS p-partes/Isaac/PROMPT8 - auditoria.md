==================================================
OBJETIVO
==================================================

Registrar operações relevantes realizadas pelos usuários.

==================================================
REGISTRAR
==================================================

Exemplos:

- criação de manutenção;
- alteração de manutenção;
- alteração de status;
- exclusão;
- criação/alteração de espaço;
- criação/alteração de usuário;
- alterações administrativas.

Registrar:

- usuário;
- pousada;
- entidade;
- ID da entidade;
- ação;
- dados anteriores;
- dados novos;
- data/hora.

==================================================
REQUISITOS
==================================================

A auditoria não deve depender do frontend.

O backend deve gerar os registros.

==================================================
ENTREGÁVEIS
==================================================

- model;
- service;
- integração com operações;
- endpoint de consulta;
- controle de acesso;
- exemplos de registros.
